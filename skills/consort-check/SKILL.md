---
name: consort-check
description: Check a randomised trial report against the CONSORT checklist and say where each item is reported.
---

Use this for the report of a randomised trial. For a trial protocol use `spirit-check`; if the design is unclear, start with `guideline-select`.

## Get the checklist

1. Ask which CONSORT version the journal requires. The statement has been revised (the 2010 and 2025 versions differ in items and numbering), so do not assume one; if the journal's instructions do not say, use the current version and state which you used.
2. Obtain the checklist text itself: a file the collaborator adds to the project, or the official one fetched with fetch_url from the CONSORT website or the EQUATOR Network (www.equator-network.org). Work from the text you obtained and do not recite items from memory. If the fetch does not return a usable checklist (many are PDF or Word downloads), ask the collaborator to add the file to the project; do not go on from memory.
3. Ask whether an extension applies and obtain it too. Common ones: cluster, non-inferiority or equivalence, crossover, multi-arm, pilot and feasibility, adaptive designs, non-pharmacological treatments, patient-reported outcomes, harms, AI interventions, and the extension for abstracts. Extension items are checked in addition to the main checklist, not instead of it.
4. Read the explanation and elaboration document for an item when its meaning is unclear, instead of guessing what it requires.

## Read

5. Read the whole manuscript: title, abstract, methods, results, discussion, the flow diagram, every table, and the supplementary files in the project (read_pdf for PDFs). If the collaborator supplies the registry record or the protocol, read those as well.

## Assess

6. For each checklist item record one of: reported, partly reported, not reported, not applicable. Give the location (section and paragraph, or page and line if the journal's form asks for them) and a brief quotation or the figure or table that supports the judgment. "Partly reported" names what is missing. "Not applicable" gives the reason.
7. Judge reporting, not conduct: an item is reported when the manuscript says what was done, including when it says something was not done. Do not infer that something was done because it is usual practice, and do not mark an item reported on the strength of a citation to a protocol alone unless the checklist allows it.
8. Cross-checks that a checklist alone does not catch:
   - participant flow: assessed, randomised, allocated per arm, received the intervention, lost and excluded with reasons, analysed. The numbers add up and agree between the text, the flow diagram and the tables;
   - the number analysed for each outcome matches the denominators in the results tables and the analysis population the methods name;
   - the planned sample size against the number randomised, with any shortfall or early stopping explained;
   - the primary outcome is the same in the abstract, the methods, the results and, if supplied, the registry record and protocol; changes after the trial began are stated;
   - each primary and secondary outcome has an effect estimate with its precision for each comparison, not only a p-value;
   - the abstract contains nothing that the main text does not, and its numbers match;
   - registration number, protocol access, funding and data sharing are stated where the checklist asks for them.

## Report

9. Produce the completed checklist as a table in the form the journal asks for (item number, item, location, and status if the form has it). Use the official item wording from the text you obtained, in its order.
10. Then give a short list of the items that need the authors' attention, most important first, with what information is needed for each, and separately any inconsistency found in step 8.
11. Suggest wording only for information the manuscript or the collaborator provides. Never invent trial details such as registration numbers, sample size calculations, randomisation or concealment methods, blinding, dates or numbers; ask for them and leave a marked placeholder.
12. Edit the manuscript only when asked. After edits, update the locations in the checklist, since page and line numbers move.
